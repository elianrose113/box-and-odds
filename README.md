# 箱球 · Box & Odds

## 如何运行

使用 Godot 4.6 标准版导入 `project.godot`，无需 .NET 或额外插件。

- **游戏**：按 F5 运行，入口为 `scenes/main.tscn`。
- **关卡编辑器**：打开 `scenes/editor.tscn`，按 F6 独立运行。
- Windows 也可将环境变量 `GODOT_EXE` 设置为 Godot 可执行文件的完整路径，再双击 `RUN.cmd` 启动游戏，或 `EDIT.cmd` 启动编辑器。

## 基础玩法

- 使用 WASD 或方向键移动角色、推动箱子。
- 小球从入口出发，根据所在格子的四向概率移动；普通地板四向各 25%，箱子的概率由箱面数字表示。撞墙时该轮原地停留。
- 调整箱子位置，在有限的小球移动轮次和推动次数内，让更多小球进入出口。
- 使用加减按钮选择投放数量，每次调整 100 颗；剩余不足 100 颗时可全部放出。每批结束后可继续调整箱子，所有批次共用小球池和推动次数。
- 累计到达数量达到目标即可通关，并解锁下一关。
